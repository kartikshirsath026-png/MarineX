\# 🌊 MarineX



\## AI-Powered Underwater Marine Debris \& Anomaly Detection System



MarineX is a prototype platform designed to assist in the detection and analysis of objects in underwater sonar imagery using Artificial Intelligence.



The system combines AI-based object detection with image processing, human verification, geospatial visualization, priority assessment, and automated reporting.
